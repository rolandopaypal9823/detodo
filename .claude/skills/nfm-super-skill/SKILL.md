## Cómo trabajar — flujos principales

### CREAR CONTENIDO (posts, guiones, emails, copies)
1. **Siempre** leer `references/01_voz_estilo_identidad.md` antes de escribir.
2. Si el contenido es para un video → revisar también `references/04_transcripciones_youtube.md`.
3. Si el contenido es de venta o habla al prospecto → revisar `references/05_avatar_alumno.md`.
4. Si necesitás prueba social (testimonios, frases, casos reales) → `references/06_casos_exito_testimonios.md`; elegí el caso por afinidad con el lector, citá el nombre real y nunca inventes.
5. Identificar la plataforma (Instagram, YouTube, LinkedIn, email). Si no se especifica, preguntar.
6. Verificar criterios de calidad antes de entregar.

### ENSEÑAR O EXPLICAR conceptos del programa
1. Leer `references/02_programa_alto_rendimiento.md` para el módulo relevante.
2. Explicar con la voz de Nico: analogías concretas, ciencia bajada a lo práctico, accionables.
3. Nunca teoría sin aplicación.

### DISEÑAR OFERTA / COPY DE VENTAS / COMUNICACIÓN CON PROSPECTOS
1. Leer `references/05_avatar_alumno.md` — es el punto de partida.
2. Usar el lenguaje textual del avatar (sección 7 del archivo).
3. Conectar con las fricciones reales y las motivaciones de compra reales.
4. Reforzar con prueba social de `references/06_casos_exito_testimonios.md` (caso afín al perfil del prospecto: Bloqueado / Ahogado / Crónico).
5. Escribir en voz de Nico (archivo 01).

### DECISIONES DE MARCA / IDENTIDAD VISUAL
1. Leer `references/03_manual_de_marca.md`.
2. Aplicar paleta (Azul NFM #0c3452 / Naranja Acción #ff6602 / Blanco #ffffff).
3. Tipografía: Montserrat Bold (títulos) + Open Sans Regular (cuerpo).
4. **Logo obligatorio:** toda pieza visual lleva el logo NFM, embebido como base64 — `assets/logo-nfm-navy.png` sobre fondo claro, `assets/logo-nfm-blanco.png` sobre fondo oscuro/foto. Ver "Identidad Visual → Archivos de logo" en el manual.

## Criterios de calidad — el contenido está bien cuando:

- Suena a un amigo inteligente hablando en el café, no a un post de marketing
- Tiene al menos UNA analogía concreta (deportiva, cotidiana, o del cerebro)
- El lector siente que aprendió algo real y accionable
- No hay una sola frase que pueda ser tildada de "motivacional vacía"
- La primera línea hace querer seguir leyendo
- Usa voseo rioplatense natural y sin forzar
- Baja la ciencia a un accionable concreto
- Cierra con pregunta reflexiva o CTA específico
